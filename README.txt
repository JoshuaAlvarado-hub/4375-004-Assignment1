Overview
The goal is to predict apartment prices using linear regression implemented in two ways:

part1.py: Linear Regression using batch gradient descent. Produces a log file and a training-loss plot.
part2.py: Linear regression using stochastic gradient descent from scikit-learn's SGDRegressor library. Also uses scikit-learn's mean_squared_error library to calculate mean squared error. Produces a log file and a training-loss plot.

Requirements
-Python 3.8+
-pip

Python packages
-pandas
-numpy
-scikit-learn
-matplotlib

Running the scripts

Run Part 1:
  powershell
  python part1.py

Run Part 2:
  powershell
  python part2.py
