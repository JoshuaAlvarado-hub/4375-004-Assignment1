Overview
The goal is to predict apartment prices using linear regression implemented in two ways:

part1.py: Linear Regression using batch gradient descent. Produces a log file and a training-loss plot.
part2.py: Compares learning rates and iteration budgets. Produces a log file and loss curves.

Requirements
-Python 3.8+
-pip

Python packages
-pandas
-numpy
-scikit-learn
-matplotlib

Running the scripts
Run Part 1:

powershell
python part1.py

Run Part 2:

powershell
python part2.py
